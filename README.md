# vendor/xiaomi/shennong

Proprietary blobs for the Xiaomi 14 Pro (shennong), generated by
device/xiaomi/shennong/extract-files.py (LineageOS extract-utils) from the stock
HyperOS OS2.0.217.0.VNBCNXM recovery ROM. Firmware partitions (proprietary-firmware.txt)
are not included: modem.img and friends exceed GitHub's 100 MB file limit.
